# A Pérola dos Sete Ventos — P0.0

Site estático de emergência hospedável em GitHub Pages.

## Estrutura
- `index.html`: início
- `ficcao/index.html`: biblioteca ECHOS OF INK
- `ficcao/cracfics/index.html`: índice de CracFics
- `ficcao/cracfics/<slug>/index.html`: páginas individuais
- `assets/style.css`: design responsivo

## Recuperação editorial
As duas ficções têm títulos, classificação, URLs e sinopses preservados. O texto integral está indisponível devido à suspensão do WordPress.com; nenhuma história foi substituída por conteúdo inventado. A recuperação exige as versões originais.

## Publicação
GitHub Pages a partir de `main` / `(root)` com `.nojekyll`.

## Direitos
Textos e arte pertencem aos respetivos titulares. Fanworks independentes não oficiais.
